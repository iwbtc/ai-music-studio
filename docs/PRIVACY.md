# AI 音乐工作室 · 隐私说明（PRIVACY）

> 版本：v1.0.0（2026-10-24）
> 一句话：**本地优先**。本应用不要求账号、不收集遥测、不上传您的工程与音频。

## 1. 我们收集什么

**不收集。** 应用没有登录、没有云端同步、没有崩溃上报、没有使用统计 SDK。
音频引擎、AI 生成器、混音建议、质量评估全部在本机运行。

## 2. 数据保存在哪里

| 数据 | 默认位置 | 是否离开本机 |
|---|---|---|
| 工程文件（当前/命名/版本历史） | `%APPDATA%\AI音乐工作室\data\projects\` | 否 |
| 导出音频（WAV/MP3/FLAC/MIDI/分轨） | `%APPDATA%\AI音乐工作室\data\exports\` | 否 |
| 导入的音频媒体 | `%APPDATA%\AI音乐工作室\data\media\` | 否 |
| 自动备份/崩溃恢复 | `data\projects\_autobackup-*`、`data\recovery\` | 否 |
| AI 桥发现文件 | `%APPDATA%\AI音乐工作室\app-endpoint.json` | 否（仅本机 127.0.0.1） |
| 界面偏好（如新手引导是否已读、收藏音色） | 本机浏览器 localStorage / Electron userData | 否 |

便携版与安装版共用上述数据目录；卸载默认保留数据（`Uninstall.ps1 -RemoveUserData` 可删除）。

## 3. 网络访问

应用**不需要联网**即可使用全部功能：
- 本地 HTTP 服务仅监听 `127.0.0.1`（供界面与 DSH 的 `studio_*` 工具通信），不对外网开放；
- 无自动更新检查、无广告、无遥测；
- 若您通过外部工具/插件另行联网，适用其各自的隐私政策。

## 4. 与 AI Agent 的交互

当您通过 DeepSeek Harness 里的 AI Agent 使用本应用时，AI 工具在本机读写工程；
对话内容是否上传取决于您使用的 Harness/模型服务，与本应用无关。
请在分享工程 JSON 前确认其中不含个人信息（工程文件只含音符/音频路径/参数，不含账号信息）。

## 5. 儿童隐私

本应用不面向 13 岁以下儿童单独收集任何信息（因为不收集任何个人信息）。

## 6. 数据删除

- 删除单个工程：应用内工程管理删除，或直接删除 `data\projects\<工程名>.json`；
- 删除全部数据：关闭应用后删除 `%APPDATA%\AI音乐工作室` 整个目录；
- 卸载时彻底删除：`Uninstall.ps1 -RemoveUserData`。

## 7. 变更通知

本隐私说明随版本分发；如有实质变更会在 `CHANGELOG.md` 与应用内帮助中说明。

## 8. 联系方式

隐私相关问题请通过项目仓库 Issue 或发布页提供的反馈渠道联系（v1.0 未提供邮件订阅）。
