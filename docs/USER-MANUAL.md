# AI 音乐工作室 · 用户手册

> 版本：v2.4.0；应用内「帮助 → 关于」显示精确版本/构建信息。
> 本手册面向普通用户；开发/二次构建请见仓库根 `README.md`、`docs/AI-COMPOSER-GUIDE.md`。

## 1. 安装

### 1.1 推荐：Setup.exe（用户级安装，无需管理员）

1. 双击 `AI音乐工作室-Setup-<版本>.exe`（自解压安装包）；
2. 在弹出的 7-Zip 自解压提示中确认，安装脚本会把应用复制到：
   `%LOCALAPPDATA%\Programs\AI音乐工作室`
3. 安装完成后自动启动；开始菜单/桌面会创建「AI 音乐工作室」快捷方式；
4. 卸载：Windows「设置 → 应用 → 已安装的应用 → AI 音乐工作室 → 卸载」，
   或运行安装目录中的 `Uninstall.ps1`。

安装包为**当前用户级**：不写 `Program Files`、不需要管理员权限；升级时覆盖安装即可，
`%APPDATA%\AI音乐工作室` 里的用户数据（工程/导出/媒体）会保留。

### 1.2 便携版（免安装）

解压/复制整个 `AI音乐工作室-win32-x64` 文件夹，双击其中 `AI音乐工作室.exe`。
便携版与安装版共用 `%APPDATA%\AI音乐工作室` 数据目录，可随时迁移文件夹。

### 1.3 系统要求

- Windows 10/11（x64）；
- 无需安装 Node.js、浏览器或 7-Zip（便携版/安装包均已内置运行库）；
- 首次启动约 32MB 采样音色库在后台加载，不阻塞界面；
- 磁盘空间：安装约 400MB，数据与导出另计。

## 2. 首次启动

- 首次打开会显示**非阻塞**欢迎卡片：3 步引导「新建模板 → 让 AI 生成 → 试听/导出」；
  点「开始创作」/「稍后」后不再显示（偏好保存在本机浏览器 localStorage）。
- 点击界面顶部「立即启用」（或任意播放按钮）解锁音频——浏览器/Electron 要求一次用户手势才能发声。
- 默认会种入演示工程《霓虹天际线 Neon Skyline》，可直接 ▶ 播放。

## 3. 界面速览

- **左栏**：通道机架（轨道列表）+ 插件库（乐器 32 / 鼓组 4 / 效果器 15，可搜索/收藏/试听）。
- **播放列表**：按小节编排 clip（pattern 片段或音频片段），支持拖动、循环、分割、裁切。
- **钢琴卷帘**：画音符、力度、延音踏板、CC lanes、量化/人性化、和弦/琶音/乐理工具。
- **混音台**：轨道/分组推子、声像、发送（Reverb/Delay）、效果器链、电平表、场景快照。
- **底部键盘**：电脑键盘演奏与录制（按 `A` 等按键弹奏，可开节拍器/吸附/录音）。
- **顶栏**：播放/停止/录音、BPM/调式、保存/打开/新建、导出、撤销/重做、帮助/关于。

## 4. 让 AI 创作（推荐工作流）

1. 在 DeepSeek Harness 对话中让 AI 调用本应用的 `studio_*` 工具（共 112 个：110 应用 + 2 启动）；
2. 常用入口：
   - 「用 house 风格生成一个 8 小节 beat」→ `studio_generate_beat`（一次调用生成 4 轨 + 编排 + section）；
   - 「要参考某个已保存工程的风格」→ `studio_analyze_reference` + `studio_generate_like_reference`；
   - 「帮我混音/看看响度问题」→ `studio_suggest_mix` / `studio_apply_mix` / `studio_ai_quality_report`；
   - 「继续补一段贝斯/和弦/主音」→ `studio_generate_part` / `studio_generate_variation`；
3. AI 每次修改都会出现在右下角「AI 修改」面板：可**接受**（保留）或**撤销**（回滚），也可在撤销后重做；
4. AI 与手动编辑共用同一工程、同一撤销栈，随时可接管继续编辑。

> AI 工具会真实读写本机工程并自动保存；不会上传工程内容（见 `PRIVACY.md`）。

## 5. 手动编辑要点

- 新建工程：文件 → 新建工程，可选 5 个模板（空白/演示/电子/钢琴/歌曲）；
- 保存：`Ctrl+S` 保存当前命名工程；「另存为」创建副本；工程版本历史最多保留 20 个；
- 撤销/重做：`Ctrl+Z` / `Ctrl+Y`（或顶栏按钮）；
- 轨道：通道机架右键或按钮可增删轨道、改音色、音量/声像/静音/独奏；
- 效果器：混音台轨道 → 效果器链，可加 15 种内置效果（滤波/失真/合唱/延迟/混响/压缩/EQ 等）；
- 自动化：钢琴卷帘下方自动化视图，可选 Read/Touch/Latch/Write 模式录制推子动作；
- MIDI：文件 → 导入 MIDI（标准 MIDI 文件），或导出 MIDI 继续在其它 DAW 制作。

## 6. 试听与导出

- 导出 WAV：顶栏「导出」→ WAV（离线渲染，含效果器与 master 链；可加混响尾音/归一化/目标 LUFS）；
- 导出 MP3（192kbps）/FLAC：同样在导出菜单；
- 导出分轨（stems）：每轨一个 WAV，便于继续混音；
- 导出 MIDI：`文件 → 导出 MIDI`；
- 导出文件默认在 `%APPDATA%\AI音乐工作室\data\exports\`，界面「导出历史」可打开所在文件夹；
- 导出前建议先 `studio_render_preview` 或播放检查是否削波（峰值接近 0dB 时会提示）。

## 7. 数据与备份

| 内容 | 位置 |
|---|---|
| 当前工程/命名工程 | `%APPDATA%\AI音乐工作室\data\project.json`、`data\projects\*.json` |
| 导出文件 | `%APPDATA%\AI音乐工作室\data\exports\` |
| 导入媒体 | `%APPDATA%\AI音乐工作室\data\media\` |
| 自动备份/版本历史 | `data\projects\_history\`、`data\projects\_autobackup-*.json` |
| 崩溃自动保存 | `data\recovery\autosave.json`（下次启动可恢复） |
| 会话恢复锁 | `data\recovery\session.lock`（正常退出自动删除；强制结束残留的**陈旧锁**下次启动会自动识别清理，有可恢复自动保存时则提示恢复） |

建议定期把 `%APPDATA%\AI音乐工作室\data` 整个目录复制到网盘/移动硬盘。
卸载默认**保留**用户数据；`Uninstall.ps1 -RemoveUserData` 才会删除。

## 8. 常见问题

见 `docs/FAQ.md`；遇到无法解决的问题，请记录：版本（帮助 → 关于）、操作系统、操作步骤、

## 9. 快捷键

| 快捷键 | 功能 |
|---|---|
| `Space` | 播放/停止 |
| `Ctrl+S` | 保存工程 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+D` | 复制选中片段/音符（依上下文） |
| `Delete` | 删除选中内容 |
| `A`（键盘面板关闭时） | 切换自动化视图 |
| `A`…`;` 等（键盘面板打开） | 演奏音符（可开录音） |
| `B` | 画笔工具（钢琴卷帘） |
| `1`–`8` | 切换编辑工具（依界面提示） |

## 10. 设置 / 更新 / 诊断 / 命令面板（R7b）

- **设置**：菜单「帮助 → 设置…」。
  - 更新通道：`stable`（默认）/ `beta`；
  - 本地使用记录：仅保存在本机，不上传、不包含工程内容；
  - 崩溃报告：写入本机 `data/crash-reports/`（最多 20 条）；
  - 语言：`zh-CN` / `en-US`（当前主要持久化偏好）。
  设置写入 `data/settings.json`，不改变工程内容、revision 或撤销栈。
- **检查更新**：「帮助 → 关于 AI 音乐工作室 → 检查更新」读取本地 `data/update-manifest.json`，
  结果分为已是最新 / 发现新版本 / 暂无更新源 / 检查失败；本版本不会联网自动下载。
- **诊断日志**：「帮助 → 帮助中心 → 导出诊断日志」生成 .txt（版本/构建/设置/工程规模/最近崩溃摘要），
  可发给支持人员；内容在本机生成，不上传。
- **命令面板**：`Ctrl/Cmd+K` 打开，输入命令名过滤，`↑/↓` 选择，`Enter` 执行，`Esc` 关闭。
  覆盖新建/打开/保存/导出 WAV/播放/停止/撤销/重做/帮助/设置/关于。
